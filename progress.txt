## Codebase Patterns

- Site: Astro 7 + Tailwind v4 in site/. Tailwind v4 `dark:` follows prefers-color-scheme unless a class-based @custom-variant is declared.
- Terminal: Worker (terminal-server/cloudflare/src/index.ts) -> Cloudflare Container (server.js, node-pty, bash). Messages: start {files, cols, rows, mode}, input, resize, signal; server sends ready, output, exit, error.
- Validation lives in validate/ (site.mjs browser checks, security.mjs WebSocket probes). Terminal checks read WebSocket frames, not screen text. Use `echo X_$((1+1))` style markers so the typed command can't match its own result.
- Local destructive probes ONLY in a capped container (--pids-limit, --memory, --cpus).
